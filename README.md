# Barrio Offline

Aplicación Android de mensajería vecinal sin Internet.

## Objetivo
Enviar mensajes entre teléfonos cercanos sin conexión a Internet.

## Primera versión
- Mensajes de texto entre dos teléfonos.
- Conexión local entre dispositivos.
- Interfaz sencilla.

## Futuro
- Retransmisión de mensajes entre dispositivos.
- Alertas vecinales.
